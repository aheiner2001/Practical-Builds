# Practical Builds Portfolio

A curated set of practical software projects and prototypes demonstrating applied skills in data science, web applications, machine learning, AI-assisted tooling, and cloud database development.

## Repository structure

- `README.md` — portfolio overview and navigation guide
- `AI-Assisted Projects.md` — AI-driven tool experiments and prompt engineering work
- `CloudDatabase.md` — cloud database application case study with Flask and MySQL
- `PickleballTrainer_C#ConsoleApplication.cs` — C# console application prototype
- `rental_neural_network/` — bike rental demand prediction using neural networks
- `streamlit_app/` — interactive Streamlit applications and utility tools
- `tool/` — standalone utilities and reference tools

## Featured projects

### Streamlit app collection

Interactive data tools and mini-apps built with Streamlit, including analytics prototypes and utility interfaces.

### Rental demand prediction

A bike rental forecast model built with TensorFlow/Keras. It uses weather, time, and calendar features to predict hourly rental demand.

### Cloud database application

A team-based cloud database project demonstrating schema design, backend integration, and task management workflows using Flask and MySQL.

### AI-assisted tooling

AI prompt engineering and productivity prototypes, including a multi-stopwatch tool, visual timers, and task tracking experiments.

## Notes

- Folder names have been standardized for improved readability: `rental_neural_network`, `streamlit_app/choose-your-own-adventure`, and `streamlit_app/image_classification`.
- Each project folder includes its own README when available.
- This repository is intended as a practical, evolving portfolio of build-focused work.
