# Streamlit App Collection

A suite of interactive Streamlit applications and experiments for data visualization, utilities, and mini project demos.

## Included projects

- `banking.py` — banking or financial dashboard utilities
- `biking.py` — bike data exploration and analysis
- `housing.py` — housing dataset exploration and model prototypes
- `pizza.py` / `pizzatest.py` — pizza ordering or classification demos
- `canvas/` — canvas utilities and API experiments
- `choose-your-own-adventure/` — interactive story-based app
- `database/` — Streamlit database examples
- `dixit/` — game support and image utilities
- `fast/` — fast backup or utility tools
- `wiggy_wash/` — service or process automation experiments
- `window/` / `window.py` — scheduling and display utilities

## Tech stack

- Python
- Streamlit
- pandas, NumPy, scikit-learn
- Web deployment with Streamlit Cloud

## Run locally

1. Install dependencies: `pip install -r requirements.txt`
2. Run a selected app: `streamlit run <app>.py`
